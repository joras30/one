# Prompt de continuidad · estado de la actualización

Continúa el Sistema Local del Laboratorio de Medidas EDESUR siguiendo la
especificación maestra V33 y entrega por fases con validación del solicitante.

La entrega actual es **fase 1 de revisión**: ejecutable Windows x64 con Python
incluido, base local vacía y separada de pruebas, servidor LAN explícito, usuario
maestro admin con clave temporal mostrada una vez, cambio obligatorio y perfil,
RBAC con equipo del supervisor, recuperación maestra solo por consola física,
auditoría encadenada, respaldo diario consistente local + dos destinos externos,
validación de integridad, estado de copias incompletas y restauración con vista
previa, contraseña, motivo y copia previa. Incluye selector claro/oscuro y avatares
vectoriales por perfil con paleta persistente.

Se conservan las mejoras anteriores de demostración: tarjetas y gráficos que
abren sus datos, tablas con búsqueda/orden/páginas/CSV, detalle con retorno,
exportaciones, explicaciones y permisos por rol. Estas vistas no equivalen a la
analítica y operación completa V33. La producción de fase 1 bloquea escrituras
operativas hasta implementar y validar fase 2.

El archivo oficial de consolidación 2026 tiene siete hojas y se conserva privado.
No publicar personas, identificadores ni registros reales en GitHub o pruebas.
El modelo debe conservar histórico, series como texto, cuentas y respaldos.

No iniciar la fase siguiente sin validar la base con el solicitante. La fase 2
implementará catálogo oficial único, identidad SAP por código + valoración,
plantillas para todas las actividades, ciclos consultables, avisos precisos de
repetición, unicidad estricta sello + color, bajas y permisos temporales. La fase
3 añadirá jornadas, metas, fichas tipo Player Card y reportes; fase 4, cierre,
etiquetas, conduce, muestreo y monitor. Mantener costo cero y ejecución sin nube.
